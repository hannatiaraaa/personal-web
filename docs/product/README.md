# Product documentation

Three documents describing this site as a product. Written after it shipped, from the decisions actually made — so they record what was done and why, not what was hoped for.

| Document | What it holds |
| --- | --- |
| [`PRD.md`](PRD.md) | Problem statement, solution, 52 user stories, implementation and testing decisions, scope boundaries |
| [`SPEC.md`](SPEC.md) | Architecture, seams, module contracts, and the technical decisions behind them |
| [`TEST-PLAN.md`](TEST-PLAN.md) | Strategy, full coverage inventory, the 24 defects found and which tier found each, traceability, residual risk |

Read the PRD for what the site is for, the spec for how it is built, and the test plan for what is actually proven.

Conventions live in [`../guidelines.md`](../guidelines.md). Run logs and review evidence live in `../private/`.
